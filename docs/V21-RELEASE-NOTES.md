# ORBITECH MASTER V21 — Visual Website Builder

## Features
- Click-to-add reusable hero, feature cards, about, CTA, contact and footer sections.
- Reorder and remove sections; edit section headlines, site title and accent colour.
- Sandboxed live preview generated locally without an AI provider.
- Download a standalone HTML preview or export the component layout as JSON.
- Save the generated page into the code workspace, with a version snapshot first.

## Run
Open `orbi/index.html` in a modern browser for the visual builder. For AI-backed features and the backend, follow `docs/README.md` and run `node server/app.js`.

## Limitations
The contact form is a visual demo and does not submit data. The visual builder does not automatically publish to hosting. Review generated markup and run the QA tools before deployment.
