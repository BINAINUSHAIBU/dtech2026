# ORBITECH MASTER V22 — Responsive Design Studio

V22 extends the local visual website builder with:

- Three built-in visual themes: Clean Light, Midnight Dark, and Warm Editorial.
- Compact, Standard, and Wide content-width settings.
- Desktop, tablet, and mobile preview frame sizing.
- Browser-local draft persistence using `localStorage`.
- JSON layout import/export with format and component validation.
- Versioned workspace saving and standalone HTML export retained from V21.

## Run

Open `orbi/index.html` in a modern browser. No AI provider key is needed for visual design features. The optional Node server and AI engine retain their existing configuration requirements.

## Notes

The preview is a local sandbox. Contact forms are demos and do not send messages. Import only layout JSON files you trust. This release does not publish a site to a hosting provider automatically.
